### صفحة التلفزيون 📺

- **قنوات عربية:** أكثر من 350 قناة باللغة العربية مصنفة تلقائيًا (قرآن ودين، أخبار، رياضة، أطفال، أفلام…)
- **قنوات عالمية:** مصنفة حسب الفئة — أخبار، أفلام، مسلسلات، رياضة، وثائقي، موسيقى…
- **مشغل مدمج:** يدعم بث HLS عبر [hls.js](https://github.com/video-dev/hls.js) مع ملء الشاشة
- **مفضلة:** احفظ قنواتك المفضلة محليًا
- **تحميل تدريجي:** عرض القنوات على دفعات لسلاسة الأداء

> ملاحظة: بعض القنوات قد لا تعمل حسب منطقتك الجغرافية أو لأنها متوقفة مؤقتًا — المصدر مجتمع مفتوح يتحدث باستمرار.

## 🚀 التشغيل كصفحة ويب

افتح `index.html` مباشرة في المتصفح، أو استضفه مجانًا عبر GitHub Pages:

1. من إعدادات المستودع **Settings ← Pages**
2. اختر الفرع `main` والمجلد `/ (root)`
3. سيصبح التطبيق متاحًا على رابط من نوع:

   ```
   https://<username>.github.io/<repo-name>/
   ```

> [!NOTE]
> بعض المحطات تبث عبر `http` فقط وقد لا تعمل عند الاستضافة عبر `https`؛
> يحاول التطبيق تلقائيًا إعادة الاتصال عبر اتصال آمن أولًا.

## 🖥️ التحويل لبرنامج ويندوز (exe)

المستودع جاهز للعمل كتطبيق سطح مكتب عبر Electron:

```bash
npm install
npm start          # لتجربة البرنامج كتطبيق سطح مكتب
npm run dist:win   # لبناء ملف exe داخل مجلد dist
```

> يتطلب تثبيت [Node.js](https://nodejs.org) على جهازك.
