# 📻 راديو الوطن العربي

تطبيق ويب لبث مباشر لمحطات الراديو من جميع الدول العربية، مبني بـ HTML/CSS/JS فقط (بدون أي إطار عمل)، مع إمكانية تحويله لبرنامج سطح مكتب لويندوز عبر Electron.

## المزايا
- تصفح المحطات حسب المنطقة والدولة (22 دولة عربية)
- بحث فوري عن أي محطة
- حفظ المحطات المفضلة (تُخزَّن محليًا)
- مشغّل ثابت مع مؤشر صوتي حي
- دعم أزرار التحكم على شاشة القفل عبر Media Session API
- تصميم متجاوب (جوال / حاسوب)

بيانات المحطات تُجلب من [Radio-Browser](https://www.radio-browser.info)، وهي قاعدة بيانات مفتوحة لمحطات الراديو حول العالم.

## التشغيل كصفحة ويب

افتح `index.html` مباشرة في المتصفح، أو استضفه مجانًا عبر GitHub Pages:

1. من إعدادات المستودع (Settings) → Pages
2. اختر الفرع `main` والمجلد `/ (root)`
3. سيصبح التطبيق متاحًا على رابط من نوع `https://<username>.github.io/<repo-name>/`

> ملاحظة: تشغيله كصفحة مستضافة فعليًا (وليس داخل معاينة مصغّرة) يضمن اتصالاً كاملاً بالإنترنت لجلب قوائم المحطات والبث.

## تحويله لبرنامج ويندوز (exe)

المستودع يحتوي أيضًا على غلاف Electron جاهز:

```bash
npm install
npm start          # لتجربة البرنامج كتطبيق سطح مكتب
npm run dist:win   # لبناء ملف exe (تثبيت + نسخة portable) داخل مجلد dist
```

يتطلب ذلك تثبيت [Node.js](https://nodejs.org) على جهازك.
